Privacy Policy for autoupload

Last updated: October 2026

What the app is

autoupload is a personal tool used by its owner to upload and schedule the owner's own videos on the owner's own YouTube channels. It runs locally on the owner's computer.

Data the app accesses

With the owner's permission (Google OAuth), the app uses the YouTube Data API to upload videos, schedule their publication, set thumbnails, and read the status and scheduled publication time of the owner's own videos. The app does not access any other Google data.

How data is used and stored

The data is used only to perform these actions. Access tokens are stored in a file on the owner's own computer. The app has no server, does not transmit data to any third party, and does not sell, share or publish any user data.

Google API Services User Data Policy

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions.
